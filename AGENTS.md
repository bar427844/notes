# AGENTS.md

Guidance for AI agents working in this repository.

## What this repository is

A public blog. It collects short pieces of writing — observations, questions, and
notes — published as plain Markdown so they are easy to read and easy to reuse.

## The text is the product

- Write for a general reader who has no context beyond the page itself.
- Keep the author's voice. The job is to polish, not to rewrite from scratch.
- Do not invent facts, examples, or opinions the author did not provide.
- Ask before deleting, merging, or restructuring existing posts.

## Editing text

- Improve grammar, wording, and flow while preserving meaning, tone, and structure.
- Prefer small, targeted changes over wholesale replacement.
- Translate any non-English text into English before publishing.
- Keep the register plain and direct; avoid jargon and filler.
- Leave formatting simple: headings, paragraphs, and lists only.

## What must not be committed

- Drafts and unpolished source material stay outside the repository.
- Only final, edited text belongs here.
- Never commit credentials, tokens, personal data, or machine-specific paths.

## Commits

- Make one logical change per commit.
- Write imperative subject lines, for example `Add post about decision fatigue`.
- Keep the working tree clean; do not commit unrelated changes together.

## Repository layout

- `README.md` — what the repository is for.
- `LICENSE` — MIT; reuse is permitted with the copyright notice kept intact.
